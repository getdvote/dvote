# dvote holding page

Static “Coming soon” page for dvote.co. Uses the existing dvote logo; no build step, JavaScript, external fonts, API or environment variables.

Publish `index.html` and `logo.svg` together at the website root. `upload.zip` contains exactly those two files for a hosting file manager or static hosting upload. Do not upload the repository or any `.env` files.

The domain registration alone currently serves a parking page. Connect static hosting and configure both `dvote.co` and `www.dvote.co` with HTTPS before calling the site live. Domain account access is required to complete this step.
